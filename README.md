# 🕌 Hyderabad Theme Portfolio

A modern and visually rich personal portfolio website inspired by the aesthetic vibes of Hyderabad city.  
Built using HTML, CSS, JavaScript, and GSAP animations.

### 🚀 Live Demo

🌐 https://web-project785.netlify.app/

---

## ✨ Features

- Modern UI Design
- Smooth GSAP Animations
- Responsive Layout
- Dark Mode Toggle
- Animated Skill Bars
- Interactive Hover Effects
- Custom Cursor Effects
- Glassmorphism Design
- Floating Shapes Animation
- Clean Project Showcase
- Hyderabad Inspired Visual Theme

---

### 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP Animation Library
- ScrollTrigger

---

## 📸 Sections Included

- Hero Section
- About Me
- Skills
- Projects Showcase
- GitHub Section
- Contact Section
